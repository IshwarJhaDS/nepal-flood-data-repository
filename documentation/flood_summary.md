# Nepal Flood and Landslide Summary – September 2024

## Introduction
In September 2024, heavy rainfall caused serious flooding and landslides in Nepal. Many districts experienced damage to infrastructure, disruption of transportation, and loss of human life. This repository organizes selected disaster-related information to help students, researchers, and others understand the impact of these events.

## Repository Contents
The repository includes province-level disaster incident statistics, district-level human-impact records, infrastructure damage estimates, and geographic reference locations.

## Organization
The data/incidents folder contains incident and affected-district datasets. The data/impacts folder contains infrastructure damage information. The data/geographic folder includes city reference points in selected affected districts. The documentation folder contains supporting reports and metadata.

## Data Limitations
The datasets contain selected figures from preliminary disaster assessments and should not be treated as complete or final statistics. Some records cover both floods and landslides. The geographic points identify reference cities, not exact flood incident sites.

## Intended Users
This collection is intended for students, researchers, disaster management personnel, and people interested in understanding floods in Nepal.
